# プロダクトコンセプト

## 概要

Liner は、一括編集に特化した macOS ネイティブの音楽タグエディタです。

多数のローカル音楽ファイルを管理しているユーザーが、1曲ずつフォームを開くのではなく、スプレッドシートのような表でメタデータを素早く修正できることを目指します。

## STEP改 / STEP_K から得た着想

STEP改 / STEP_K は、Windows における一括音楽タグ編集の強力なワークフローを長く支えてきたタグエディタです。

Liner は、特に以下のような体験から着想を得ています。

- 1ファイルを1行として扱う
- 多数のタグを同時に見渡せる
- セルを直接編集できる
- 行や列をまたいでコピー&ペーストできる
- 一括置換や変換ができる
- トラック番号を連番生成できる
- タグをもとにファイル名を生成できる
- 将来的にファイル名からタグを生成できる

この着想への敬意を明確にしつつ、Liner は macOS 専用アプリとして独自に設計・開発します。STEP改 / STEP_K の公式 Mac 版、移植版、派生版、互換版ではありません。

## Macらしい新解釈

Liner は、Windows ユーティリティをそのまま macOS に移したようなアプリではなく、最初から Mac のために設計されたアプリとして作ります。

「Macらしい新解釈」とは、以下のような方向性です。

- サイドバー、ツールバー、中央の表、右側インスペクタ、シートを使った macOS ネイティブな画面構成にする
- Finder からのドラッグ&ドロップを主要な読み込み導線にする
- 右側インスペクタで、選択中の楽曲や複数選択時の共通値・混在値を編集できるようにする
- 値が混在しているタグを自然に表現する
- 編集、変換、リネーム、アートワーク、ウィンドウ操作を macOS メニューとして整理する
- macOS 標準のキーボードショートカットと期待に沿う
- ファイル名変更など破壊的な操作の前にはプレビューシートを表示する
- 将来的な自動化は Shortcuts や AppIntents を前提に設計する

プロダクトの中心はあくまで表編集です。Mac 専用の設計は、その表編集をより分かりやすく、安全で、速くするために使います。

## 想定ユーザー

Liner は、以下のようなユーザーを想定します。

- Apple Music とは別に、または並行してローカル MP3 ファイルを管理している
- アルバム単位でメタデータを丁寧に整えたい
- ファイル名、トラック番号、カバーアート、タグの一貫性を重視する
- 多数の楽曲をまとめて修正したい
- Web アプリやクロスプラットフォームアプリではなく、Mac ネイティブアプリを好む

最初のユーザーは開発者自身とし、広い市場向けの装飾よりも、実際の音楽ライブラリ整理で役に立つことを優先します。

## 主なユースケース

- 同じアルバム名やアルバムアーティストを複数曲に一括で貼り付ける
- `01`, `02`, `03` のようなトラック番号を生成する
- artist、title、genre、year、comment をアルバム単位で修正する
- 1枚のカバー画像をアルバム内の全トラックに適用する
- `{track} - {title}.mp3` のようなテンプレートでファイル名を変更する
- 保存前に、タグ変更とファイル名変更の差分を確認する
- 破壊的な変更が静かに実行されないという安心感を得る

## MVP対象

MVP では MP3 / ID3v2 を優先します。

重要な ID3v2 フィールド:

- title
- artist
- album
- album artist
- track number と total tracks
- disc number と total discs
- genre
- year または date
- comment
- cover artwork

ID3v2.3 と ID3v2.4 の扱いは、最初の書き込み方針を決める前に調査します。

## 将来対応

FLAC 対応は初期設計で考慮しますが、最初の実装必須範囲には含めません。

将来の FLAC 対応では以下を扱います。

- Vorbis Comment
- FLAC picture block
- Liner 共通メタデータモデルと FLAC 固有形式のマッピング

M4A、AAC、OGG、WAV などの他形式は、MP3 ワークフローが安定した後に検討します。
